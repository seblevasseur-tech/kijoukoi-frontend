Importation depuis Excel

Vous pouvez importer plusieurs joueurs simultanément en remplissant un fichier Excel.

1. Télécharger le modèle

Récupérez le modèle Excel pré-formaté pour voir les colonnes attendues.

2. Uploader le fichier

Sélectionnez votre fichier Excel (.xlsx) rempli avec les données des joueurs.
